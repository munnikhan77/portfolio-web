# Munni Khan — Cinematic Portfolio

Nuxt portfolio with filmic motion, letterbox hero, and scroll-driven scenes.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit `app/data/portfolio.ts` for name, bio, projects, skills, and social links.
More real content can be dropped in anytime — the structure is ready.

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run preview` — preview production build
